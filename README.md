# Lab2
# TaskHub GUI

Тема: Розробка графічного застосунку для керування списком завдань.

Мета: навчитися створювати GUI-додатки на Python та реалізувати базові операції керування даними через графічний інтерфейс.

## Файли проєкту

1. `taskhub_cli.py` - консольна частина TaskHub CLI.
2. `taskhub_gui.py` - графічний застосунок на Tkinter.
3. `tasks.json` - файл, у якому автоматично зберігаються завдання.

## Підтримувані CLI-команди

```bash
python taskhub_cli.py add "Купити продукти"
python taskhub_cli.py list
python taskhub_cli.py edit 1 "Купити продукти і воду"
python taskhub_cli.py done 1
python taskhub_cli.py delete 1
python taskhub_cli.py clear
```

## Запуск GUI

```bash
python taskhub_gui.py
```

## Реалізовані можливості

- додавання завдання;
- перегляд списку завдань;
- редагування завдання;
- видалення завдання;
- позначення завдання як виконаного;
- очищення списку;
- збереження завдань у JSON-файл;
- перевірка порожнього введення;
- перевірка вибору завдання перед редагуванням, видаленням і позначенням виконання;
- підтримка операцій TaskHub CLI через `subprocess`.
